# safeapricot.com

Safa'nın kişisel sitesi. Saf HTML / CSS / JS, GitHub Pages üzerinde.

## Dosyalar

- `index.html` – ana sayfa
- `kitap.html` – kitap sayfası
- `style.css` – tüm stiller (`#e2925c` ve koyu mod / highlight yeşili `#02be3d`)
- `main.js` – üstteki ip menü, dil (TR/EN), koyu/açık tema, otomatik yaş/sınıf hesabı, gizli kodlar
- `furrets/` – profil fotoğrafı (`uykulufurret.JPEG`) ve tatlı Furret çizimleri

## Sık değişecek şeyler

- **YouTube / Kick linkleri:** `main.js` en üstteki `LINKS` + `index.html` içindeki "Sosyal Medya" bölümü
- **Yeni gizli kod:** `main.js` içindeki `SECRET_CODES` nesnesine bir satır ekle
- **Profil fotoğrafı:** `furrets/uykulufurret.JPEG` (veya `assets/profil.png`)
